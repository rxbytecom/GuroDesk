# Licensing

GuroDesk is **free for all teachers**. It was developed by **Raymart Hernandez**.

Starting with version 1.9.0 there is no trial period, license code, activation file or payment. Every feature works on every computer, offline. Teachers may copy and share the installer with other teachers.

Earlier versions (1.8.7 and older) used offline device activation. When such an installation is upgraded to 1.9.0, its school records are kept and the old activation file in the app-data folder is no longer read.
